# 💳 Credit Card Fraud Detection System

A Machine Learning based web application built using Python and Streamlit to detect potentially fraudulent credit card transactions.

## 🚀 Features

- 📊 Interactive Dashboard
- 💳 Fraud Transaction Detection
- 🤖 Logistic Regression and Random Forest models
- ⚖️ SMOTE for handling class imbalance
- 📈 Model Performance Comparison
- 🔍 Confusion Matrix and ROC Curve
- 📊 Feature Importance Analysis
- 📋 Data Explorer

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Imbalanced-learn
- Matplotlib
- Seaborn

## 🧠 Machine Learning Models

- Logistic Regression
- Random Forest Classifier
- SMOTE for dataset balancing

## 📁 Project Structure

credit-card-fraud-detection/
├── app.py
├── requirements.txt
└── README.md

## ▶️ How to Run

Install the required packages:

    pip install -r requirements.txt

Run the Streamlit application:

    streamlit run app.py

## 👩‍💻 Project

This project was developed as a Machine Learning project to demonstrate fraud detection, data analysis, model comparison, and interactive visualization using Streamlit.
